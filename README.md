# 小影子 · 教室助手

为一间教室设计的云端教室摄像头工具。鸿合白板安装采集端，录像保存在云服务器，老师使用手机或电脑打开网站观看，不要求校园局域网互通。

0.2 功能：单人实时预览、默认关闭的自定义时间表录像、最近 2/3 天自动清理、无声 MP4 回放和下载、最长 20 秒的语音喊话、一次性白板绑定和远程维护。

## 开发启动

需要 Windows 10/11 x64、Node.js 22.12+。默认调试使用合成摄像头/麦克风，无需开启物理设备。

```powershell
npm ci
npm run check
npm run dev:cloud
```

命令自动打开本机 HTTPS 网站和白板采集端。终端显示初始密码；登录后进入“录制与设置”，生成绑定码并填入采集端。网站与采集软件分开运行，模拟将来云端部署。

按 `Ctrl+C` 结束，调试数据保留在 `data/cloud-dev/`。开发入口仅信任该次服务的证书，不修改系统证书、防火墙或登录项。真实摄像头调试、正式部署和排错见 [云端运维](docs/CLOUD.md)。

```powershell
$env:XY_CLOUD_ORIGIN = 'https://你的正式域名'
npm run dist
```

打包输出为 `release/XiaoYingZi-Setup-0.2.0.exe`，为面向教师的用户级安装器。构建脚本将上述域名写入安装包；没有域名的调试包允许手填地址，不能直接作为正式交付包。

教师无需安装 Node.js、配置网络或安装证书。安装采集端并输入一次网站绑定码即可；手机/电脑直接通过网站访问。采集安装包不含云服务器、TLS 域名或公网部署凭据。

## 数据

云端 `/data` 保存 SQLite 设置、录像、临时语音与访问凭据；白板仅在 Electron 用户目录保存 DPAPI 加密的设备绑定。关闭窗口后托盘继续运行；从托盘退出会停止采集。白板关机、休眠或断网时无法上传云录像，不提供离线补传。

当前未部署公网服务器，未验证鸿合真机；自动检查结果和剩余验收项见项目进度。
