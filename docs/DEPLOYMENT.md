# 白板与手机部署

此文档仅为 0.1 局域网版历史参考。当前 0.2 云端版使用 `docs/CLOUD.md`，不要求教师配置 IP 或证书。

## 先检查设备

1. 白板进入 Windows 桌面，查看“设置 → 系统 → 关于”。第一版面向 Windows 10/11 x64。
2. 用 Windows“相机”确认顶部摄像头可用；关闭相机和其他占用摄像头的软件。
3. 确认白板有可用磁盘空间。720p、15 FPS 是请求的默认采集规格，实际由设备协商；录像空间以真机测量为准。
4. 手机、办公电脑和白板需能互访；校内无线、教学 VLAN 可能相互隔离。

## 白板启动

将打包好的 `XiaoYingZi-0.1.0-win-x64.exe` 放入固定目录再运行。Windows 可能提示未签名程序，校方设备策略可能需要管理员协助。

控制台显示 IP 地址、初始访问密码、根证书导出按钮和数据目录。选择校园网卡地址，避免 VPN/虚拟网卡地址。白板没有摄像头任务时处于待命，首次观看或录像时才打开摄像头。

关闭控制台窗口会缩到托盘；托盘菜单“退出并停止采集”会退出。需要开机运行时，在打包版控制台主动勾选“Windows 登录后自动启动”。便携程序移动路径后需重新设置登录项。

## Windows 防火墙与固定地址

仅向学校可信网段放行 TCP 8443；WebRTC 视频还需要局域网设备之间的 UDP 通信。Windows 首次弹窗时仅允许合适的学校网络，不必开放公网访问或路由器端口映射。

如果管理策略限制软件或 UDP，请由学校网管按应用和实际校园网段配置规则。项目不会自行修改防火墙。

建议由网管为白板设置 DHCP 地址保留。启动时会根据当前网卡地址签发证书；IP 改变后重启程序并使用新地址，根证书保持不变。

## 手机/电脑信任 HTTPS 证书

每台白板有自己独立的局域网根证书。**只分发 `xiaoyingzi-root.crt`，不要分发 `root-key.pem` 或任何私钥。** 可在白板导出后通过可信方式传到观看设备。

### Windows 观看电脑

双击 `.crt`，安装到“当前用户 → 受信任的根证书颁发机构”。重新打开浏览器，通过白板显示的 `https://校园IP:8443` 访问。完成后应没有证书错误。

### iPhone / iPad

打开 `.crt`，按提示下载描述文件；在“设置 → 通用 → VPN 与设备管理”安装，再到“设置 → 通用 → 关于本机 → 证书信任设置”启用对应根证书的完全信任。使用 Safari 打开白板地址，按住说话时允许麦克风。

### Android

不同品牌路径不同，通常为“设置 → 安全/更多安全设置 → 加密与凭据 → 安装证书 → CA 证书”。浏览器对用户 CA 的支持和学校管控策略需要实测，推荐新版 Chrome/Edge。

如果设备不允许安装证书，先完成实时观看验证，再确认受管理的证书部署方案；不能承诺所有手机仅跳过证书警告就能录音。微信内置浏览器不作为第一版验收浏览器。

## 开始使用

1. 登录后点击“开始观看”。画面是白板摄像头拍摄的教室，无声音。
2. 到“录制与设置”添加星期/时段，选择保留 2/3 天，打开定时录像并保存。初次安装开关关闭。
3. 时间表按北京时间执行。只有按“保存设置”后才生效；重启保留已保存配置。
4. 录像约每 5 分钟成段，结束后转为 MP4，处理完成才可回放/下载。
5. 按住说话并允许麦克风，松手后发送，最长 20 秒。留意“已播放”状态；先测试白板扬声器音量。

## 录像与运维

- 数据默认位于 `%APPDATA%/xiaoyingzi-classroom/data` 附近，准确位置以控制台“数据目录”为准。
- 录像与程序安装目录分开存储；重装程序不要删除数据目录。
- 剩余空间低于 1 GB 时暂停新片段，释放空间后会重试。
- 程序关闭或断电后，重启尝试恢复已写入片段；无法恢复的片段显示失败。
- 不关闭白板、不休眠。仅关闭显示屏能否继续运行要真机确认。Windows/Android 切换是否影响采集也要现场验证。
- 记录初始密码并修改为个人密码；修改后本地初始密码文件会删除。
- 忘记密码时不要删除整个数据目录；当前版本由开发维护人员备份数据库后重置密码配置，保留录像与证书。

## 无法访问时

先在白板确认本地服务运行，再在办公电脑测试 TCP 8443，最后检查手机无线网络。能登录但没有视频时，检查摄像头权限/争用、UDP 防火墙和校园网络隔离。能观看但不能录音时，检查 HTTPS 证书信任、浏览器麦克风权限，并使用系统浏览器打开。
