# 验证与验收

## 自动检查

`tests/e2e/guide.spec.ts` 检查教师图文说明与自适应布局：实际改变浏览器窗口后页面随之变宽，1920/1440/1280/1024/768/390/320px 下四个页面无横向溢出，电脑观看操作位于可视区域。验证安装包下载及未发布状态、说明入口跳转、FAQ 展开，不使用真实摄像头画面作为测试素材。

0.2 新增 `tests/cloud.test.ts`：一次性绑定、过期/限速、令牌持久化/替换/撤销、Host/Origin/登录边界、TURN 凭据与配置。`tests/e2e/cloud.spec.ts` 使用真实安装引导、独立云端服务、Electron 和浏览器，验证绑定、视频解码、停止观看仍云录像、喊话、重启凭据与撤销。开发调试命令见 `CLOUD.md`。

Linux CI 增加 Docker 镜像构建、Compose 配置和 Caddy 配置验证；本机没有运行 Docker daemon 时不能把此项列为本机通过。公网 TURN 必须强制 relay 检查，当前合成端到端不验证中继可达。

`npm run check` 覆盖设置校验、北京时间/跨午夜时间表、认证、录像权限和上传、保留清理、类型检查和生产构建。

浏览器测试使用独立临时数据目录、随机端口、合成摄像头和麦克风。不得读取用户真实摄像头，不修改系统证书，不复用实际访问密码。端到端测试只绕过测试上下文证书验证，不改变正式程序的 HTTPS 策略。

`tests/e2e/classroom.spec.ts` 包含两个用例：浏览器采集夹具与实际 Electron 桌面端。前者覆盖 WebRTC 视频实际解码、停止观看仍录像、无声 MP4 解码/回放/下载、语音播放确认、390px 布局；后者验证真实 preload、桌面采集、停止观看仍录像、FFmpeg 转码和扬声器播放状态。测试使用 Windows 视频采集兼容开关，具体原因见 ADR-007。桌面用例使用 8443 端口，运行前关闭本项目其他实例。

打包运行测试通过 `XY_DESKTOP_EXE` 指向实际打包 exe，命令见开发文档。`test-results/` 保留本轮截图；失败时保留 trace 和页面错误上下文，不提交其中临时令牌或密码。

## 交付门槛

| 门槛         | 证据                                                      |
| ------------ | --------------------------------------------------------- |
| 逻辑和 API   | 测试命令、通过数量和失败明细                              |
| 可构建       | 类型检查和 Vite / tsc 退出码                              |
| 媒体链路     | 合成摄像头直播、录像转 MP4、静音校验、语音播放确认        |
| Windows 交付 | NSIS 包生成、实际展开资源的绑定与媒体验证、隔离机覆盖升级 |
| 教室可用     | 以下真机清单由实际设备执行                                |

## 鸿合真机清单

- [ ] 确认 Windows 版本、硬件型号、摄像头及扬声器设备。
- [ ] 白板安装引导预填正确网站，一次性绑定成功；安装/启动不要求教师配置网络或证书。
- [ ] 办公电脑和手机能打开公开网站并登录；证书无错误。
- [ ] 校园网络及手机其他网络分别观看，确认 relay 候选和 TURN 转发可达。
- [ ] 网站撤销绑定后旧设备无法重新连接；更换设备、重新绑定和覆盖升级保留凭据分别验证。
- [ ] 首次打开画面确认拍摄方向、画质、帧率和延迟。
- [ ] 录制初始关闭；默认不会产生录像。
- [ ] 添加一段近期时段，开启后自动开始，时段结束自动停止。
- [ ] 关闭观看页面，录像仍持续。
- [ ] MP4 在目标手机与电脑上播放、快进、下载，无教室音轨。
- [ ] 录制持续超过两个分段，检查切段间隙是否可接受。
- [ ] 录音松手后白板扬声器播放；20 秒上限、切后台取消正常。
- [ ] 麦克风拒绝授权、摄像头占用时有可理解的错误提示。
- [ ] 两个页面同时打开时旧页面停止，新页面能观看。
- [ ] 网络中断恢复，页面重新观看与定时录像能恢复。
- [ ] 程序重启恢复已保存设置，处理中录像尝试恢复。
- [ ] 保留期限到期清理；磁盘低空间停止新录像并提示。
- [ ] 关闭窗口后台运行；显式退出停止采集；开机启动按用户选择生效。
- [ ] 教学软件和屏幕关闭/双系统切换不会意外停止所需录像。
- [ ] 至少一个完整教学日的稳定性、CPU、磁盘和温度观察。

自动化合成媒体测试通过只说明软件链路可运行，不能替代鸿合驱动、校园出口、公网 TURN、手机兼容和现场稳定性验收。
