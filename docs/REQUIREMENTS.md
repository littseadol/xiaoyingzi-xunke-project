# 需求基线

确认日期：2026-11-03。用户已授权在当前目录开发第一版。

## 当前变更：0.2 云端版（优先于以下 0.1 基线）

用户要求异地维护：网站、设置、录像与回放部署到阿里云 Linux 服务器；白板仅安装采集软件，主动连接云端。教师不安装根证书、不配置学校防火墙/端口/IP，不执行终端命令。网站使用公开可信 HTTPS。

首次流程为网站登录 → 下载采集端 → 网站生成一次性绑定码 → 白板输入绑定码（正式包预填网站）→ 显示已连接。绑定后重启自动重连；首次连接页提供 Windows 登录后运行选项。普通网站更新不要求重新安装客户端；采集脚本更新需重开采集端，桌面壳升级通过新版安装器覆盖安装，暂不承诺静默自动升级。

保留一间教室、单观看者、静音录像默认关闭、时段/2–3 天保留/松手喊话。云端录像需要白板持续联网，断网时不承诺离线录像补传；中断片段尽力恢复。云端配置临时 TURN 凭据用于跨网连接；公网转发、带宽和真实校园出口必须现场验证。

用户确认暂未租服务器/域名，先在本机调试；云端保存录像已确认。设备系统/摄像头仍待鸿合真机确认。源码仓库为 `https://github.com/littseadol/xiaoyingzi-xunke-project.git`。

## 0.1 历史场景

使用者为一名教师。一间鸿合教室白板提供自带摄像头，教师在办公室用手机或 Windows 电脑访问；设备都连接学校局域网。观看对象是摄像头拍摄的教室，不是屏幕。

## 0.1 历史功能

1. Windows 白板采集端，手机/电脑响应式网页观看，单个观看页面占用连接。
2. 手动开始/停止实时观看；无人观看时的录像不受影响。
3. 定时录像初始关闭。可编辑星期、时间段，支持多个时段和跨午夜。
4. 用户保存“启用”后按时间表执行，退出重启保留已保存设置。
5. 时间表固定使用 Asia/Shanghai，不依赖电脑配置的时区。
6. 静音录像，约每 5 分钟一个独立片段，结束后生成 MP4。
7. 保存 2 或 3 天，默认 3 天；按录像结束时间计算期限。
8. 按日期查录像、播放、下载和手动删除。
9. 按住录音、松手上传、白板扬声器播放，最长 20 秒。取消/切换后台时不发送。
10. 单密码登录；自动生成初始密码，可修改。
11. HTTPS 局域网服务和本机独立根证书；不依赖公网 STUN/TURN、CDN 或云 API。
12. 状态真实显示白板在线、摄像头错误、正在录制和喊话播放结果。

## 0.1 原范围（云端变更已覆盖其中相关项）

外网访问、多教室、多人观看、账号体系、云存储、教室声音监听、录像带声音、实时双向对讲、Android 原生采集、AI 行为识别、白板屏幕监控。

## 设备前提与待确认项

- 鸿合设备实际 Windows 版本/CPU/硬盘空间，顶部摄像头是否向 Windows 开放。
- 是否安装 OPS，以及切换 Android/Windows 时摄像头归属与采集进程运行状态。
- 同校网络之间是否存在 VLAN/无线客户端隔离。
- 手机类型、浏览器、是否允许安装并信任本机证书。
- 与教学软件同时访问摄像头时的兼容性；第一版不承诺争用共享。
- 运行期间不关机、不休眠，录像目录有足够可用空间。

## 交付定义

源码可构建、自动检查通过、可生成 Windows 程序、有部署和验收文档，视为开发版交付。只有一台实际鸿合白板和目标手机完成 `TESTING.md` 现场清单后，才可称为可在该教室正式使用。
