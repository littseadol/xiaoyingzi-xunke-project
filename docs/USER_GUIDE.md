# 面向教师的使用说明

产品内入口：登录网站后，电脑左侧或手机底部点击「使用说明」。完整图文在页面内，无需打开开发文档。说明图是操作示意，示例时间和绑定码不能用于连接，不使用真实教室或用户摄像头照片。

## 面向使用者的内容

1. 手机和办公电脑只需打开网站；白板小助手仅装在教室白板，首次安装一次。
2. 教室白板进入 Windows 并联网，关闭占用摄像头的软件；下载、双击安装包，按提示完成，打开小助手。
3. 网站「录制与设置」生成 12 位绑定码，在白板小助手输入并连接；绑定码 10 分钟内有效、只能用一次，网站显示「白板在线」才表示连接成功。
4. 日常在「实时教室」点「开始观看」，看的是教室摄像头；本版没有教室声音，点「停止观看」结束预览。
5. 录像默认关闭。添加星期/时段，选择保留 2/3 天，开启并保存；时间按北京时间，白板须开机联网。停止观看不取消录像计划，关机/休眠/断网会影响录制，无离线补传。
6. 「录像回放」选日期/片段，回放或下载；约每 5 分钟分段，结束处理后可回放，过期或删除无回收站。
7. 按住说话、松手后白板播放，最多 20 秒。第一次允许浏览器麦克风权限；需检查白板音量，软件完成播放不代表现场一定听清。
8. 常见问题：离线、摄像头占用/黑屏、没有教室声音、找不到录像、喊话无声、换手机、忘记密码和更新安装。

## 维护约定

- 内容在 `src/client/guide.tsx`，图示及布局在 `src/client/guide.css`，导航由 `src/client/main.tsx` 提供。
- 教师说明用按钮的实际中文名称；避免出现服务器配置、证书安装、端口或终端命令。
- `/api/config` 返回安装包状态；只有可下载时才展示真实下载链接，下载仍需登录。未准备好、请求失败都明确提示联系帮忙设置的人。
- 本机试用地址明确提示不能直接当作教室安装地址，正式安装包由维护者预设公开网站域名。
- 参考图不当作真实设备或安装验收证据；运行流程变化时同步更新说明、图示和测试。
- `tests/e2e/guide.spec.ts` 验证窗口真实缩放、7 种屏幕宽度、4 个页面无横向溢出、观看操作可见、6 幅图示、下载可用/缺失、说明跳转和常见问题展开。
